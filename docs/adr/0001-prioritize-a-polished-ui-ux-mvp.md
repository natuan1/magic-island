# Prioritize a Polished UI/UX MVP

Desktop Island will optimize the MVP around a highly polished native Island experience before broad feature coverage. The first product scope is Media, File Shelf, Clipboard History, Timer, Quick Actions, shortcuts, menu bar, settings, multi-display basics, updater, and direct distribution; Calendar, Mirror, system monitoring, AI, plugins, and cloud sync stay out of MVP.

**Considered Options**

- Ship a full productivity dashboard immediately.
- Ship media-only with maximum polish.
- Ship a focused productivity surface with Media, Shelf, Clipboard, Timer, and Quick Actions.

The focused productivity surface wins because it exercises the core UI/UX patterns: Compact Activity, Expanded Island, drag target, local content history, and action flows. If the Media vertical slice is not excellent, later productivity features should wait.
