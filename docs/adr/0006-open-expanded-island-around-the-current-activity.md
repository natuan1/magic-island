# Open Expanded Island Around the Current Activity

The Expanded Island should lead with the Current Activity, then expose Home View navigation to Media, File Shelf, Clipboard History, Timer, and settings-adjacent actions. Home View must stay small and navigational rather than becoming a broad dashboard.

This keeps the product anchored in what is happening now. Users should not have to scan a control center when they opened the Island because a track changed, a file was dropped, or a timer finished.
