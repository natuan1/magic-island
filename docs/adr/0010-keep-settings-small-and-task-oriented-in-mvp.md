# Keep Settings Small and Task-Oriented in MVP

MVP Settings should expose only the controls needed to make the Island comfortable and trustworthy: launch at login, feature toggles, display choice, hover delay, clipboard retention, shortcuts, updater behavior, and permission status. Appearance controls should be limited to a few presets before adding detailed sliders.

The raw plan contains many possible appearance and behavior settings, but a UI/UX-first product should not ship a heavy control panel before the core Island interaction is polished.
