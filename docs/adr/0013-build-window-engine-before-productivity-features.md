# Build Window Engine Before Productivity Features

The first implementation sequence is Window Engine, then Island Engine, then Media vertical slice, then productivity features. Shelf, Clipboard, Timer, and Quick Actions should wait until NSPanel positioning, notch and floating geometry, passive focus, hover Peek, expansion animation, interactive mode, and display disconnect handling are proven.

This is the highest-leverage UI/UX decision in the raw plan. If the Island does not feel native, fast, and stable, more features will only make the product feel heavier.
