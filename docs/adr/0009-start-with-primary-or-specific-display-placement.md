# Start with Primary or Specific Display Placement

MVP display behavior should support a selected display and a Primary Display fallback. Follow-cursor, all-displays, active Space mirroring, and richer multi-display behaviors are deferred until the base Island feels correct on notch, non-notch, and external-monitor setups.

This reduces early UI instability. The Island is a spatial object; unpredictable movement across displays would hurt trust more than a smaller initial display feature set.
